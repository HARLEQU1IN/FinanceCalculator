# Финансовый калькулятор (Desktop, PySide6)

Приложение для планирования личных финансов с распределением дохода по модели 50/25/15/10, учётом расходов/доходов, вкладом/процентами, графиками, целями и бюджетами, экспортом в CSV/Excel и автобакапами.

## Возможности
- Распределение дохода: 50% обязательные, 25% рост, 15% стабильность, 10% вознаграждения
- Транзакции: добавление расходов, редактирование, теги, фильтры (поиск/тег/месяц)
- Графики: доходы/расходы/нетто по месяцам, круговая по категориям, стек расходов
- Вклад и прогнозы: простые/сложные проценты
- Цели и бюджет: цели по growth/stability, месячные лимиты по категориям
- Конвертер валют: актуальные курсы из интернета
- Экспорт: CSV и Excel (.xlsx)
- Хранение данных: SQLite (`finance.db`) + миграция из `data.json`
- Автобэкап: по интервалу, ротация (хранится последние 10), восстановление

## Установка
```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

## Запуск
```bash
python -m app.main
```
